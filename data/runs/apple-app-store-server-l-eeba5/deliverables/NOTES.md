# Notes
- The README's install command (`pip install app-store-server-library`) gets the package from PyPI. The goal is to install the clone, so I ran `uv venv --python 3.12 /work/venv` and then `uv pip install /work/app-store-server-library-python`. Python 3.12 comes with Ubuntu 24.04. The install worked with no pins and no patches.
- The README doesn't explain how to use the bundled test certs. The test CA has no authority key identifiers, so verification with `testCA.der` fails with VERIFICATION_FAILURE unless `verifier._chain_verifier.enable_strict_checks = False` is set. The repo's own `tests/util.py` sets this the same way.
- Results: the notification decodes as TEST, the transaction decodes (bundleId com.example), a wrong bundle id is rejected (status 2), the promo signature verifies with the public key from testSigningKey.p8, and the receipt gives transaction id "0", which is what the repo's tests expect. 325 repo tests pass; the async test needs the optional httpx extra, so I skipped it.
